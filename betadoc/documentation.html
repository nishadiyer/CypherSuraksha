Install

npm install
npm run models          # optional: NER + deepfake models (downloads, checksum-verified)
npm run build           # type-check, bundle, manifest/CSP gate
npm run package         # zip for the Chrome Web Store

Open chrome://extensions, enable Developer mode, choose Load unpacked and select dist/. Without model files the extension still works using deterministic fallbacks. There are no accounts or logins anywhere in the product, so there are no demo credentials.

User manual

Click the toolbar icon. The popup has four tabs and a sun/moon button for light and dark themes.

Shield

The ring shows how many of the three shields are armed. Three counters show prompts redacted, photos cloaked and calls checked (counts only, never content). Each defense card has its own switch: PromptGuard, Pixel Cloak, TruthLens. Under TruthLens is the experimental face-swap detector, off by default.

Page

Tells you whether CypherSuraksha is running on the tab you are viewing, whether it found the message box and send button, how many placeholders it remembers, and the latest video reading. Use "Show a test notification on this page" to confirm the on-page UI works.

Vault

Add words that must never reach an AI chat. They are stored only as salted one-way hashes, so they cannot be listed back. "Remove all keywords" asks you to click twice.

Sites

Trusted sites: on these, CypherSuraksha stands down completely.

On-page messages

  • Toast (bottom right): tells you a prompt was redacted.
  • Badge near an upload: "Cloaking photo…" then "Cloaked", with "Bypass on this site".
  • Pill on a video: green "No fake found", amber "Unsure", red "Fake?", grey "No face". Hover for the numbers.
  • Warning: "This video may be AI-generated" after sustained red.

A day in the life

  1. Morning, ChatGPT. You paste an email thread to summarise. A toast confirms names, addresses and a phone number became placeholders. The summary comes back with the real names restored on your screen.
  2. Lunch, Reddit. You upload a holiday photo. The badge says "Cloaking photo…", then "Cloaked". The file the site receives has no GPS data and a faint, invisible change over faces.
  3. Afternoon, Google Meet. A "colleague" asks for an urgent transfer. The pill stays red and the warning appears. You hang up and call them on a number you already know.
  4. Evening, the popup. The Shield tab shows today's counters. You add a project codename to the Vault so it is blocked from every chat from now on.

Technical architecture

src/background   router, offscreen singleton manager, per-tab session store, ledger
src/content      interceptors (prompt, upload, video) and ui/ (closed Shadow DOM)
src/offscreen    registry, workers, shields (privacy, pixel, people), ORT loader
src/popup        Preact popup (tabs, theme, diagnostics)
src/shared       messages, settings, vault, base64 helpers
src/types        shield contract

Stack: Chrome Manifest V3, Vite with crxjs, Preact, Tailwind, onnxruntime-web. Permissions are only offscreen, storage, activeTab, scripting, plus host access to the listed sites.

PromptGuard

Regex detectors (emails, phones, SSN, Luhn-valid cards, API keys) merge with INT8 BERT NER spans and your hashed list; overlaps resolve by priority. A restorer swaps placeholders back in replies, handling text split across nodes. For controlled editors it uses editing strategies and re-verifies afterward; if it cannot confirm the redaction, it fails safe and never sends the original.

Pixel Cloak

UltraFace finds faces; a per-image EOT-PGD optimisation against FaceNet models (momentum, random crop scale and shift, exact resize adjoint) produces a change clamped to ±8/255 across overlapping faces. Output is re-encoded, which strips metadata.

TruthLens

Frames are sampled at 0.5–2 fps, the largest face is cropped (30% margin), scored by a ViT classifier (FP32 on WebGPU when a real GPU exists, INT8 on WASM otherwise), and smoothed over 5 frames: amber from 40%, red from 70%. The warning needs 3 sustained reds. One pill per video source.

Shield contract

All shields implement src/types/shield.ts.

ShieldRequest  { requestId, shield, tabId, domain, payload }
ShieldResponse { requestId, action: ALLOW | MODIFY | WARN | BLOCK,
                 data?, confidence, latencyMs }

There is no network API: the only interface is message passing between content scripts, the service worker and the offscreen document.

Limits to know about

  • Chat-site selectors target today's page markup and may need updates when sites change.
  • Cloaking works against FaceNet-class recognisers (97.5% down to about 30%) but barely dents ArcFace (95%). It is a speed bump, not a guarantee.
  • AI-generated faces are caught well; face-swaps are not reliably caught. The optional detector can only show amber, and once misread a real webcam.
  • Demo pictures are stills; live video behaves differently.
  • Prompt redaction without the NER model catches structured data and name cues, not arbitrary names.
  • Restoration skips editable areas such as ChatGPT's canvas, by design.
  • JavaScript strings cannot be zeroed; zero-fill applies to typed arrays and tensors.

Demo guide

npm run fixtures        # sample pictures (public research datasets)
npm run demo:prepare    # copies three pictures into demo/media/
npm run build:demo      # separate DEMO extension in dist-demo/

Load dist-demo/ (its name ends "(DEMO build)") and keep only one CypherSuraksha enabled. Serve demo/ on http://localhost:4186/.

Switch modes on a fresh tab for a clean reading; the pill smooths over 5 frames.

Testing

npm test                 # 67 unit tests
npm run test:e2e         # drives real Chrome against stand-in pages
E2E_REAL_GPU=1 npm run test:e2e   # use the real GPU (Apple Metal)

The end-to-end suite covers the CSP, redaction, popup, upload, video and model gates. Live-site checks (ChatGPT, Claude, Gemini, Copilot, Reddit, Google Meet) were done by hand and are recorded in the repository's phasedoc.

Privacy

No data collected, sent or stored beyond: settings, the hashed vault, three counters, and a per-tab redaction map in session storage. See PRIVACY.md.

CypherSuraksha beta. Everything runs on your device. Built on open-source models: bert-base-NER (MIT), FaceNet, UltraFace, CommunityForensics and GenD, each under its own licence (see MODELS.md).
